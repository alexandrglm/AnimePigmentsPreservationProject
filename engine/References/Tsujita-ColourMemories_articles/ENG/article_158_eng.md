# Color Design Notes [Tsujita Kunio]
## Episode 158: Long Ago... 96 1995 Part 16 Weekly Art Meetings! September and October

Everyone! Have you finished your tax returns? This year's tax return deadline is March 14th! Last year I thought "ah, next year I'll ask a tax accountant!" but ultimately this year was also self-calculated & document preparation. "Ah, next year for sure..." Well, but I'll probably do it myself next year too... (distant look).

...Actually, at the time I'm writing this manuscript, I haven't finished this year's tax return yet (explosion). The plan was for it to be properly finished by the time this manuscript appears - should be, should be, should be? (sweat)

Now, will it happen!?

Anyway.

*Neighborhood Story* finally began broadcasting. Production proceeded almost smoothly. Art & color direction meetings were set roughly weekly, and character color checking progressed at roughly the same pace.

Character setting work procedure: for main character settings, we'd make costume change bases from basic design character settings drawn by Umakoshi-san, then Costume Designer Kawamura-san would draw costume changes on top of those base settings like "dress-up dolls."

Main appearing characters were seven people: Mikako, Tsutomu, Jiro, Yusuke, Risa, P-chan, and Mariko. Characters would increase further in the latter half, but these costume changes happened every episode. About 7 outfits appeared each episode at one per person. Well, after accumulating episodes, clothing would accumulate and some reuse became possible, but this series also followed seasons somewhat, so summer clothes, winter clothes... Since it was a year-long story, each character had considerable clothing.

For main characters, guest character and prop settings appearing in each episode were principally drawn by each episode's animation director. Combined with earlier main settings, we created quite a number of color settings each episode.

Making color samples from those character settings - all color samples were cel paintings. Cel paint coloring. Even starting to use Mac, we were still far from current digital coloring levels of painting settings on screen and making color samples. Having all those color samples painted with cel paint and finished into cels myself would be quite time-consuming, so we had company finishing staff paint them. But first, I myself needed proper color images.

In previous works, I'd carefully paint setting copies with multiple colored pencils to create my own images, but that was forced mental conversion. When thinking mentally, quite specific cel paint number color images already exist in my head, but naturally, cel paint and colored pencils are completely different. No matter how much I convinced myself with paint numbers, it only became division instruction samples when making cel color samples. Moreover, that itself took considerable time - couldn't I create images closer to finished painting? That had been a long-standing concern.

Then I noticed certain color marker pens at an art supply store. A series called "Copic." Trying them out (trial coloring), these were very good. Being alcohol markers, they could be painted quickly and uniformly, and above all, had good color development. So I bought almost all available colors at light speed (laugh). Boom! Set them up at both work room and studio. Come to think of it, these Copics were also at Yazawa-sensei's workplace.

Using color copy paper, I'd place coloring conceived mentally onto black and white copied character line art using these Copics. Why use color copy paper? Because color copy paper had much better ink adherence and finished color development than ordinary copy paper. Painting with Copics that developed colors close to cel paint numbers I was thinking of meant finished Copic settings had quite similar atmosphere to cel images. Then I'd specify colors again with paint numbers and have finishing staff paint color sample cels.

Using Copics, I gradually wanted colors "between this color and that color, like paint number ◯◯" - colors other than manufactured ones. So I'd blend and mix supplementary inks myself, creating and using new original color Copics (laugh). Gradually becoming a maniac (laugh).

That much - this method of thinking character colors using Copics was revolutionary for me. Mac was also new weaponry, but this was immediate combat power! Anyway, since I could reproduce color images conceived with coloring quite close to cel finishing, not just character color samples, but for complex pattern still color direction, I could paint divisions and place colors myself using this, confirming my own images while making finished images and detailed divisions easier to convey when requesting cel trial painting.

While handling *Neighborhood Story* character setting color work daily like this, another work was actually operating in parallel behind the scenes. Such was autumn 1995.
